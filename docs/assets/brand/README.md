# Personal JT branding assets

These files reuse Jason Twyman's original white-and-blue interlocking JT mark, also used in his approved LinkedIn banner. The logo was not redrawn or regenerated.

Source file: `Jason_Twyman_GitHub_Avatar_JT.png` (1254 x 1254 pixels).

Source SHA-256: `2d6daed068295d9b54aee8582b4863b112c1fa9ca95eece4e157a8cf6e5e354b`.

## Preparation

The source was cropped to the square rectangle `(202, 191, 1059, 1048)` (right/bottom exclusive), trimming excess background while preserving the complete mark and a small margin. The native navy background was retained; no transparency was fabricated.

Images were converted to metadata-free RGB and resized with Pillow's Lanczos filter. The header uses a lossless WebP encoding of the resized pixels; the PNG and ICO variants support browser-tab icons. These are branding assets, not lab evidence.
